I'm not worried about write + delete being bundled, as a malicious user could write a blank file over the previous if they wanted. I'm essentially aiming for a similar feel/functionality to a shared LAN drive in that regard. That said, we do have the soft delete/Trash functionality, but currently no way to access it. This may be the better option to have the Write still work the same, but a separate permanent delete for owners/managers to be able to go into the Team's trash folder and permanently delete from there. This is likely a bigger change, as we will need to update the UI such that each Team (or personal) has a way to access "Recently Deleted" while still respecting the user's read/write permissions within. E.g. If User A doesn't have access to ExampleSubfolder and another user deletes a file within it, User A shouldn't be able to see/interact with that file in the trash. So the trash will need to likely just flag for deleteion, hide from view in that folder, and display it in the Trash. Should have a file name, link to folder it was deleted from, deleted by [user], permanent deletion on [date], and a button to Recover. Default sorted by soonest-to-be-wiped at the top. Should have filter options (name or folder), checkboxes to select more than one file, then a Bulk Recover option if more than one is selected, and a Bulk Permanently Delete for those with the permanent delete option.
